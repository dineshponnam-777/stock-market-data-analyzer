# 📈 Stock Market Data Analyzer



An industry-oriented Stock Market Analytics Dashboard built using Python, Streamlit, Pandas, Plotly, and Yahoo Finance API.



This application fetches real-time stock market data, performs financial analysis, calculates stock indicators, and visualizes market trends through an interactive dashboard.



---



# 🚀 Features



- Real-time stock market data fetching

- Yahoo Finance API integration

- Moving average analysis

- Daily return analysis

- Volatility analysis

- Trading volume visualization

- Interactive Streamlit dashboard

- Downloadable CSV reports

- Financial KPI analytics

- Interactive charts using Plotly



---



# 🎯 Project Objective



The goal of this project is to build a stock market analytics system capable of:



- Fetching live stock market data

- Performing financial analysis

- Visualizing stock trends

- Calculating volatility and returns

- Generating interactive dashboards

- Supporting investment analysis workflows

| Technology | Purpose |

# 📦 Installation



## Clone Repository



```bash

git clone https://github.com/your-username/stock-market-data-analyzer.git

```



## Move into Project Folder



```bash

cd Stock-Market-Data-Analyzer

```



## Install Dependencies



```bash

pip install -r requirements.txt

```



\---



# ▶️ Run Application



```bash

python -m streamlit run app.py

```
